# تفسير القرآن بالقرآن

تطبيق ويب يعرض لكل آية **الآيات الأخرى التي تبيّنها من داخل القرآن نفسه**، دون أي تفسير خارجي.
يُذكر سبب كل رابط حتى يتحقق القارئ بنفسه.

## الخوارزمية

لكل آية V تحصل كل آية أخرى W على درجة:

```
الدرجة(V, W) = 1.0 × الجذور + 1.0 × العبارات + 1.0 × التعبير + 2.0 × السياق
```

1. **الجذور واللمّات المشتركة**: متجه TF-IDF لجذور كلمات الآية ولمّاتها، ثم تشابه جيب التمام.
   الجذر النادر وزنه أكبر من الجذر الشائع مثل «قول».
2. **العبارات المتطابقة**: تسلسلات من 2 إلى 4 كلمات تتطابق بعد حذف التشكيل.
   العبارة النادرة أهم، ولا تُحسب العبارة إلا إذا فيها كلمتان لهما جذر على الأقل
   (فلا تطغى صيغ مثل «وما أدراك ما»).
3. **التعبير المشترك بصيغة أخرى**: أزواج لمّات متقاربة (بينها كلمتان على الأكثر)، فتتطابق
   ﴿أَنْعَمْتَ عَلَيْهِمْ﴾ (الفاتحة 7) و﴿أَنْعَمَ ٱللَّهُ عَلَيْهِم﴾ (النساء 69) رغم اختلاف الصيغة.
   لا يُحسب إذا تطابقت العبارة حرفيًا، حتى لا يُعدّ الشيء مرتين.
4. **السياق والبيان الداخلي**: قواعد على النص:
   - ﴿وما أدراك ما ...﴾ ← الآية التالية التي تجيب عنها (مثل ﴿الطارق﴾ ← ﴿النجم الثاقب﴾).
   - الآية التي تبدأ بـ«الذين/الذي/التي» ← الآية السابقة التي تصفها
     (مثل ﴿هدى للمتقين﴾ ← ﴿الذين يؤمنون بالغيب﴾).
   - ﴿هل أتاك حديث…﴾ و﴿هل أنبئكم…﴾ و﴿هل أدلكم…﴾ في آية قصيرة ← الآية التالية التي تجيب
     (مثل ﴿هل أتاك حديث الجنود﴾ ← ﴿فرعون وثمود﴾).

تُرتّب الآيات وتُعرض أعلى 10. الحساب يتم مرة واحدة لكل الآيات (6236) ويُحفظ في ملفات JSON،
فيعمل التطبيق في المتصفح دون خادم خاص.

لا يستعمل التطبيق أي نموذج مدرَّب على نصوص خارج القرآن. جُرّب تعلّم المعاني من القرآن وحده
(LSA وPPMI)، فلم يحسّن النتائج لصغر حجم النص، فلم يُعتمد.

## التشغيل

```bash
python3 tools/build.py          # يحسب الروابط ← web/data/*.json
python3 tools/evaluate.py       # يقيس النتائج على أمثلة معروفة
python3 -m unittest discover tests
python3 -m http.server -d web 8000   # العنوان: http://localhost:8000
```

لا يحتاج إلا Python 3 (المكتبة القياسية فقط).

## الواجهة

- اختيار السورة والآية، أو الرابط المباشر مثل `#2:255`.
- الآية مع الآية السابقة والتالية (السياق)، ثم «الآيات المفسِّرة» مع سبب كل رابط.
- النقر على كلمة يعرض كل مواضع جذرها في القرآن.
- البحث بكلمة، أو بجذر بكتابة `جذر:رحم`.

## التقييم

`tools/evaluate.py` يتحقق من 15 مثالًا معروفًا يبيّن فيه القرآنُ القرآنَ.
النتيجة الحالية: **12 من 15** ضمن أعلى 10 نتائج. الأمثلة الثلاثة الباقية
(﴿بظلم﴾ ← ﴿إن الشرك لظلم عظيم﴾، وكلمات آدم ← الأعراف 23، والمائدة 1 ← المائدة 3)
تربطها المعاني لا الألفاظ.
